# Bouncing Ball

A simple JavaScript canvas animation that renders multiple moving balls that bounce off the browser window edges and react to collisions.

## Preview

This project uses:
- `HTML5 Canvas`
- `Vanilla JavaScript`
- `CSS`

## Features

- Full-screen canvas animation
- Multiple balls with random position, velocity, and size
- Edge bouncing physics
- Ball collision detection
- Color updates on collision

## Project Structure

```text
.
|- index.html   # App markup and canvas element
|- style.css    # Basic page styling
|- main.js      # Animation, Ball class, collision logic
```

## Run Locally

No build step is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/<your-repo>.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

Tip: For best results, use a local server (for example VS Code Live Server extension), though this project can run by directly opening the HTML file.
